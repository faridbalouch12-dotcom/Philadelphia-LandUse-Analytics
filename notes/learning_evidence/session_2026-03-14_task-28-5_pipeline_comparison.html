Tradeoff Analysis

Gained

Simpler pipeline — 3 steps instead of 5
No file management or disk layout to maintain
Traceability lives in DB alongside the data
3 tasks collapsed — less overhead, same learning

Lost

No offline inspection without Docker running
Volume wipe = must re-hit API (no local backup)
Acceptable for 18 rows — revisit for permits
