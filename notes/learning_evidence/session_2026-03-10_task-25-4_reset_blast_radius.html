Recovery path after each reset

Level 1

  1. Recreate analytics schema
  2. Run Python agg script

Level 2

  1. Recreate 3 schemas
  2. dbt run (full DAG)
  3. Run Python agg script

Level 3

  1. Recreate 5 schemas
  2. Re-ingest all 4 sources
  3. dbt run
  4. Run Python agg script

Level 4

  1. docker compose down -v
  2. docker compose up --wait
  3. Re-ingest all 4 sources
  4. dbt run
  5. Run Python agg script
